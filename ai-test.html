Sicily Travel Deals Test

Local test page for the D&L AI sales assistant widget.

This is a local test page.

It loads the floating AI assistant widget so you can check the look and behaviour locally. The chat button appears in the bottom-right corner and the chat box also auto-opens after about 20 seconds.

The widget talks to /ai-proxy.php, which forwards requests to the AI backend running on the server. Until these files are uploaded to the Hestia subdomain, the backend will not respond — that is expected. The UI will still open and show a friendly "not connected yet" message instead of breaking.

This page sets data-ai-context="Sicily travel page" on the <body>, so the widget sends "Sicily travel page" as the page context. You can still ask about other destinations (e.g. Morocco) — the backend agent handles destination switching.

Try the quick buttons (Family trip, Couple trip, Morocco instead, Need custom plan) or type your own message.
